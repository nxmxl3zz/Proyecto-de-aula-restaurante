## Revisión integral de UI/UX

Las capturas vigentes incluyen tarjetas por unidad, controles de adicionales, grupos de mesas, búsqueda de inventario y filtros de reportes. Inicio muestra una atención guardada con la acción Continuar. La nueva suite `ExperienciaUsuarioTest` genera los paneles en dos tamaños y comprueba la visibilidad de las acciones principales.

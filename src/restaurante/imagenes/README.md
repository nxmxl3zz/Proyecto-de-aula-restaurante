# Imágenes PNG de La Doble

Estos archivos se generaron con la herramienta integrada ImageGen. Son imágenes independientes; Java sólo las carga y escala con `ImageIcon`. No son pantallas aplanadas ni fotografías dibujadas con código.

Reemplazar un PNG conservando su nombre y reconstruir el proyecto para cambiarlo. Los platos nuevos usan una imagen de referencia según su nombre o categoría; los combos comparten la foto de su hamburguesa. Las imágenes ilustran el menú de demostración.
